| ID | Этап | Результат |
|---|---|---|
| CP2-01 | UX и спецификация | Мобильные и десктопные макеты, API-контракты, модель угроз |
| CP2-02 | Фундамент | React PWA, FastAPI, PostgreSQL, авторизация, CI |
| CP2-03 | GitHub | Управление токеном из UI, webhook, репозитории, PR и CI |
| CP2-04 | Проекты | Импорт GDD и планов, дорожная карта, зависимости, задачи |

| CP2-07 | Согласования | Очередь решений, уведомления, аудит, ограничения полномочий |

## Первое задание CP2-01
В отдельной ветке подготовить UX-сценарий: подключение GitHub → создание проекта → импорт плана → выдача задания → проверка PR → согласование. Подготовить один адаптивный прототип, API-контракты и матрицу полномочий. Скриншоты, отдельный визуальный отчёт и тест-план не требуются. Без изменения VPS, без секретов и платных сервисов. PR на проверку директору.

Все этапы разрабатывать в отдельных ветках с PR. Для обычной приёмки достаточно зелёного релевантного CI; дополнительные скриншоты, видео, обязательные количественные квоты тестов и отдельные отчёты запрещено навязывать. В main только после зелёного CI и проверки границ безопасности. См. docs/CI_POLICY.md.
