## Первое задание CP2-01
В отдельной ветке подготовить UX-сценарий: подключение GitHub → создание проекта → импорт плана → выдача задания → проверка PR → согласование. Сделать макеты 390×844 и 1440×900 в обеих темах, API-контракты, матрицу полномочий и тест-план. Без изменения VPS, без секретов и платных сервисов. PR на проверку директору.

Все этапы разрабатывать в отдельных ветках с PR. В main только после проверки.
