# CreatePortal 2.0: концепция

Цель: русскоязычный центр управления разработкой нескольких проектов. Режим Б: ИИ-директор самостоятельно планирует, выдаёт задания, проверяет GitHub и CI, но важные решения согласует с владельцем.

## Пользовательский путь
1. Владелец подключает репозиторий и описывает цель.
2. Система импортирует документацию, дорожную карту, PR и CI, сохраняя ссылки и даты.
3. Директор предлагает этапы, зависимости и критерии готовности.
4. Владелец утверждает существенные изменения.
5. Исполнители получают ограниченные задания, директор отслеживает выполнение и проверяет PR.
6. Деплой и необратимые действия выполняются только после отдельного разрешения.

## Разделы
Сегодня; Проекты; Задачи; Директор; Разработка; Память; Настройки.

## UX
Android PWA и десктоп, адаптивность от 360px, русский язык, Forest Glass 2.0, светлая и тёмная темы, доступность.

## MVP
Проекты, GitHub, задачи, согласования, журнал решений, память, базовый ИИ-директор с ручным режимом. Без обязательных платных API.
